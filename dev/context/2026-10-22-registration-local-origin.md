# Ошибка регистрации при локальном запуске

## Причина

Сервер, запущенный обычным `nuxt dev`, слушал только `::1:3000`. `127.0.0.1:3000` возвращал ECONNREFUSED, хотя `BETTER_AUTH_URL` задан именно этим адресом. При открытии через `localhost` регистрация получала 403 `INVALID_CALLBACK_URL`: callback строился от адреса страницы, который не совпадал с разрешённым origin. PostgreSQL и Mailpit работали.

## Исправление

- Dev-сервер закреплён на `127.0.0.1:3000` в Nuxt-конфигурации.
- Middleware перенаправляет только GET/HEAD страниц `/`, `/ru/**`, `/en/**` между локальными loopback-алиасами на настроенный origin при совпадающих протоколе и порте. Путь и query сохраняются; ответ не кешируется.
- API и внешние домены не перенаправляются, доверенные origins не расширены. Формы и ссылки из писем используют один адрес.
- Обновлены инструкции запуска и проверки перенаправлений в Playwright.

Диагностическая отправка с заведомо пустым именем не создала аккаунт. Пользовательские учётные записи и пароли не изменялись.

## Проверка

- Перезапущен проверенный Nuxt dev-процесс этого проекта. Теперь `127.0.0.1:3000/ru/register` отвечает 200; `localhost:3000/ru/register` — 302 на настроенный адрес. Ошибка callback исчезла: заведомо невалидное имя получает ожидаемый 400 `INVALID_NAME`.
- Lint, typecheck и production build проходят.
- Playwright проверяет localhost/IPv6 Host, сохранение query, отсутствие перенаправлений для внешних хостов и API. Существующие проверки недоверенных Origin/CallbackURL сохранены.
- Дополнительная тестовая отправка регистрации в первом прогоне исчерпала общий лимит попыток. Дублирующая отправка заменена чтением API; настройки безопасности приложения не менялись.
- Итоговый прогон `auth.spec.ts memorials.spec.ts`: **15 passed, 3 skipped**. Проверены RU/EN, desktop/mobile, регистрация с письмом в Mailpit, подтверждение, вход, восстановление пароля и создание сохранённого мемориала.
