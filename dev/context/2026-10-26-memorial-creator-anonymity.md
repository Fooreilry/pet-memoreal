# Создатель места памяти и анонимность

## Задача

Показать имя создателя в полной карточке мемориала и добавить выбор анонимного размещения при создании.

## Решение

- Форма содержит необязательный чекбокс «Остаться анонимным». Для новых мест по умолчанию отображается имя из профиля; фамилия и email не публикуются.
- Сервер хранит `is_anonymous` у мемориала. Публичный `creatorName` равен текущему имени владельца либо `null` для анонимного места. Владелец берётся только из сессии.
- Полная карточка показывает создателя или «Анонимно». Вымышленные примеры не получают фиктивных авторов.
- Миграция сохраняет старые записи анонимными. Анонимность не меняет владение и доступность записи в кабинете; повторное сохранение с тем же ключом учитывает этот выбор.

## Проверки

- `db:generate`, локальный `db:migrate`, `lint`, `typecheck`, `build`: успешно.
- `test:unit`: 4 passed; `db:test`: 1 passed.
- Playwright (`memorials`, `account`, `garden-header`, `theme`): 36 passed, 3 skipped; один сценарий пересёкся с фикстурой хедера на месте lake-3. Фикстуры хедера перенесены на lake-8/9.
- Повторный прогон `memorials` и `garden-header`: 20 passed, 2 skipped. API и миграция пропускаются в mobile, поскольку проверены в desktop.
- Проверены оба языка и размера экрана: имя автора, анонимность, ошибка и повтор отправки, idempotency с неизменной анонимностью, гостевой просмотр и перезагрузка, отсутствие приватных полей в JSON. Тест миграции проверяет старую и новую записи на временной таблице.
- Скриншоты формы и карточки просмотрены на desktop/mobile. Сценарии используют временную локальную БД; облачные базы, публикация и GitHub не затрагивались.
