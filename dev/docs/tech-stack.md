# Технологический стек

| Область | Выбор | Роль в проекте |
| --- | --- | --- |
| Приложение | Nuxt 4, Vue 3, TypeScript, Nitro | Страницы, серверный рендеринг и API |
| Интерфейс | Nuxt UI, Tailwind CSS 4 | Формы, кабинет владельца, администрация |
| Сад | PixiJS 8 | Отрисовка и взаимодействие с 2D-сценой в браузере |
| Языки | `@nuxtjs/i18n` | Русский для России, английский для остальных стран; URL без языкового префикса, ручной выбор сохраняется |
| Данные | PostgreSQL, Drizzle ORM, Neon | Пользователи, мемориалы, общие лимиты авторизации и миграции |
| Вход | Better Auth + Drizzle adapter | Сессии, регистрация и роли |
| Почта | Nodemailer, Resend SMTP | Подтверждение email и восстановление пароля; локально Mailpit |
| Размещение демо | Vercel, Node.js 24 | Nuxt SSR и Nitro API; регион Frankfurt |
| Файлы (запланировано) | S3 API, AWS SDK, Sharp | Зависимости установлены; загрузка фотографий пока не реализована |
| Проверка данных | Zod | Входящие данные форм и API |
| Качество | ESLint, vue-tsc, Node test runner, Playwright | Стиль, типы, настройки деплоя и пользовательские сценарии |

Локально инфраструктуру поднимает Docker Compose: PostgreSQL 18.6, SeaweedFS 4.47 и Mailpit 1.31.2. Порядок запуска описан в [локальных сервисах](local-services.md). SeaweedFS — локальная реализация S3 API; внешний поставщик файлового хранилища ещё не выбран. Настройка облачного демо описана в [Vercel + Neon + Resend](vercel-deployment.md).

Nuxt UI используется для обычных экранов. PixiJS ограничен сценой сада и подключается только в браузере. Реализованы регистрация, подтверждение почты, вход, выход, восстановление доступа, кабинет и создание мемориала на свободном месте сада. Миграции создают схему и четыре сада карты; seed повторяемо добавляет справочные сады. Детали — в [инструкции по авторизации](authentication.md) и [созданию мемориалов](memorial-creation.md).
