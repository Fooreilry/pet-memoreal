# Ревью форм и внутренних страниц

## Область и проблемы

Проверены вход, регистрация и восстановление, кабинет, админка, создание и редактирование места памяти. Frontend Design Premium применён к product/admin-интерфейсам с сохранением принятой палитры, шрифтов и геометрии. Источники поведения: [авторизация](../docs/authentication.md), [мемориалы](../docs/memorial-creation.md), [права](../docs/roles-and-administration.md).

| Наблюдение | Решение |
| --- | --- |
| Телефон тратил место на повторное рекламное вступление перед формой | Компактная шапка, поля выше, декоративный текст только на широком экране |
| Подписи/данные мелкие, панели и цвета немного различались | Единая paper-поверхность, читаемые подписи, поля 16px, основные цели 44px, спокойные радиусы |
| Длинная форма питомца выглядела сплошным списком | Разделы о питомце, история, подпись автора; счётчик и auto-grow текста с ограничением высоты |
| Native выбор сада/роли отличался от списка животных | Общие Nuxt UI списки с локализацией, клавиатурой и согласованной геометрией |
| Уход со страницы/закрытие редактора теряли черновик | Общие `useUnsavedChangesGuard` и `UnsavedChangesDialog`, без сохранения личного текста в browser storage |
| Админка длинная; refresh скрывал данные; смена роли без подтверждения | Навигация по разделам, occupancy meter, сохранение читаемого снимка, повтор, подтверждение роли и безопасный фокус |
| Глобальный h2 увеличивал заголовки диалогов; кнопка закрытия мелкая | Общий диалоговый заголовок 24px и цель закрытия 44px, без изменения имени питомца в полной истории |
| Красный текст soft-alert имел контраст около 3.23:1 | Тёмные semantic-токены, soft-уведомления и более тёмные hover/active кнопок; отдельный браузерный тест контраста |
| Выход отзывал сессию до согласия отбросить черновик | App-scoped registry активных guard: подтверждение до POST, inert pending-диалог, ограниченное ожидание и проверка сессии при неопределённом ответе |
| Clamp списка мемориалов мог конфликтовать с черновиком роли | Независимая мемориальная пагинация сохраняет role drafts; подтверждение связано со сменой пользовательского набора |
| Отмена перехода из исчезнувшего меню теряла клавиатурный фокус | Profile-ссылка сохраняет нативное поведение, отменённая навигация возвращает фокус на кнопку аккаунта |
| Spinner добавлял ширину кнопкам сохранения | Постоянный значок подтверждения резервирует место; размеры проверяются на задержанной настоящей отправке |

## Согласованность и границы

Поведение зафиксировано в [UX-CONTRACT.md](../../UX-CONTRACT.md), визуальные источники — в [DESIGN.md](../../DESIGN.md), владельцы компонентов и команды — в `premium-ui.json`. Nuxt UI получает RU/EN locale на уровне `UApp`.

Серверные права, подтверждение почты, безопасные перенаправления, модель анонимности и размещение в чанках сохранены. После создания/редактирования открывается полная карточка в том же саду. В кабинете остаются красный выход, круглый аватар и карточки без кнопки создания. Ошибки формы сохраняют введённые значения. Роль и удаление подтверждаются; обычное сохранение дополнительного подтверждения не требует.

## Проверки и доказательства

- До изменений запущены 74 E2E: 57 passed, 12 skipped, четыре устаревших ожидания удалённой landing-кнопки и один вход с реальным лимитом 429. Устаревшие ожидания исправлены, финальные suite запускаются раздельно.
- Unit: 91/91. Финальные lint, typecheck и production build выполнены успешно; `git diff --check` чистый. Зависимости и lockfile не менялись.
- Финальные команды и сценарии перечислены в `premium-ui.json`; результаты находятся в `test-results/product-*`.
- `product-foundations.spec.ts`: 8/8 — действительные error/success тексты и primary hover имеют контраст не ниже 4.5:1; scrollbar доступен в обычном/forced-colors режиме; обе library-owned кнопки садов открываются с клавиатуры.
- Strict audit: unresolved owners 0; обе native-select находки устранены. Остались два статических ложных срабатывания на настоящие `UPopover` trigger-кнопки в садах; они проверяются с клавиатуры в `product-foundations.spec.ts`. Отчёт хранится в `test-results/product-design/audit.json`.
- `designmd lint` выполняется без добавления зависимости в проект. Предупреждения о токенах, описанных в prose mapping, не означают отсутствия runtime-значений (Model B).

Промежуточные тестовые исправления: геометрия popup измеряется после анимации, клавиатура ожидает настоящий фокус ReKa; тестовые записи после параллельной вставки повторно находятся на своей странице. Windows Chromium process crash исчез при одном worker для тяжёлых garden/memorial suite. Проверки приложения не ослаблялись; лимиты auth не отключались.

Проверены RU/EN на 1440px desktop и 390px touch viewport, 320px reflow форм, reduced motion, клавиатура, реальные dropdown/modal open states, loading/error/empty/retry, сохранение и возврат. Это браузерная эмуляция, а не проверка на физических устройствах или полный native 200% zoom matrix. Рост удобства/конверсии количественно не измерялся.

Черновики остаются только в памяти текущей страницы. Браузерный unload использует штатное предупреждение; переходы внутри приложения — собственный диалог. Это не autosave и не восстановление после подтверждённой перезагрузки.
