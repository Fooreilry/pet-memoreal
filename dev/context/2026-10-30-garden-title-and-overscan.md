# Временный заголовок и запас сцены для отдаления

## Проблема

Название сада постоянно занимало центр верхней части карты. При обратном переходе масштаб canvas уменьшался ниже 1, поэтому у его краёв открывался фон контейнера.

## Решение

- Название показывается на три секунды после готовности нового сада и исчезает за 150мс. Загрузка не расходует этот интервал; возврат из истории и отмена входа в другой сад его не перезапускают. H1, его доступное имя, фокус и document title сохраняются.
- Логический viewport, проекция, пользовательская камера и DOM-маркеры остаются прежними. Только backing canvas и сцена имеют скрытый запас по всем сторонам: `size × (1 / 0.84 − 1) / 2 + 32px`. Дополнительные 32px закрывают край blur.
- Stage смещён на размер запаса; сам canvas имеет противоположный CSS-отступ. За рамкой заранее нарисованы окружение, продолжения дорожек, детали соседних чанков, фон крупного плана и погода.
- Snapshot хранит исходные логические размеры и запас, чтобы переключение renderer bounds и resize не смещали композицию. Используется прежний renderer, snapshot ограничен 1024px, кеши окружения/фона — 2048px. Общий ambient ticker остаётся 30fps.
- Pixi преобразует `filterArea` из локальных координат слоя: её начало должно быть `(-margin.x, -margin.y)`, чтобы после смещения stage погода покрывала весь backing. Шейдер переводит расширенные UV в исходный логический viewport; бюджет погодного прохода остаётся 768px.
- При отмене входа в историю после resize карта пересчитывает проекцию и границы камеры перед показом. Снимок не оставляет карту с геометрией прежнего размера.

## Проверка

- `lint`, `typecheck`, `build` — успешно; `test:unit` — 120/120.
- Новые overscan/title сценарии и повтор длинного window-flow — 18/18 desktop/mobile. Проверены все края четырёх садов, реальный отдаляющий переход, крупный план, дождь в запасе, resize → отмена, камера/фокус и полный трёхсекундный интервал после медленной загрузки. Снимки desktop/mobile просмотрены.
- Широкая регрессия — 86/88 до исправления двух тестовых фикстур. Длинному window-flow потребовался лимит 60с вместо 30с; повтор прошёл. В статичной роще отличались ровно 39px по дробному краю маски гаснущего H1, остальные пиксели совпадали во всех трёх повторах. Целочисленная тестовая маска с запасом 1px исправляет сравнение; финальный surfaces-прогон — 10/10, точное сравнение PNG сохранено. Совокупно проверены 104 уникальных браузерных сценария.
- Strict UI audit: 0 unresolved, два известных ложных срабатывания для триггеров Nuxt UI `UPopover` (их действие предоставляет библиотека; реальные меню/помощь проверяются браузером). Design lint: 0 ошибок, 16 предупреждений о runtime CSS-потребителях токенов Model B.
