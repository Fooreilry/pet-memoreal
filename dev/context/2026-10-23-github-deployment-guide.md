# Публикация демо через GitHub

## Контекст

Пользователь уточнил, что проект уже находится в GitHub, аккаунты Resend и Neon созданы. Нужна инструкция с импортом репозитория и объяснением происхождения доменов.

## Изменения

- Основной путь в `dev/docs/vercel-deployment.md` заменён на импорт GitHub через кабинет Vercel, настройку Production-переменных и Redeploy.
- Разделены предоставляемый Vercel адрес сайта, собственный домен отправителя и ограниченный тестовый отправитель Resend для почты владельца аккаунта.
- Описаны получение постоянного адреса после технического деплоя, настройка `BETTER_AUTH_URL`, DNS, добавление SMTP key как `SMTP_PASSWORD` и административные команды из локального `.env.vercel`.
- Указано, что GitHub-деплой не получает локальные изменения, а GitHub Actions сам по себе не задерживает Vercel до окончания проверок. Preview требует отдельной конфигурации.
- CLI оставлен дополнительным способом работы с существующим проектом.

## Проверка

Шаги сверены с официальными инструкциями Vercel GitHub/Domains и Resend SMTP/Domain verification/Testing domain. Прочитан итоговый Markdown. Код приложения и настройки сервисов не менялись, автоматические тесты не запускались. Коммиты и отправка в GitHub не выполнялись.
