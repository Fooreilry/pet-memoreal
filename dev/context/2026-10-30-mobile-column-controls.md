# Компактная колонка мобильного управления

## Проблема

Горизонтальная полоса управления занимала слишком большую часть визуализации на телефоне. Кнопки переходов и возврата выглядели массивно по сравнению с доступным пространством карты.

## Решение

- Масштабирование и раскрытие второстепенных действий образуют узкую вертикальную колонку справа. Сброс, разворачивание, погода, пауза, помощь и доступная диагностика открываются через More в подписанном вертикальном меню Nuxt UI.
- В обычном состоянии меню закрыто. Все действия сохраняют области касания 44×44px, доступные имена, фокус и клавиатурное управление. Вложенная помощь закрывается раньше основного меню; переключения остаются доступными без повторного раскрытия.
- Компактное оформление действует до 600px и на coarse-pointer экранах до 1000px, включая горизонтальное положение телефона. Desktop сохраняет прежние размеры и компоновку.
- В крупном виде памятника погода и пауза расположены колонкой шириной 44px. Информация и возврат используют кнопки высотой 44px с меньшими отступами и иконками 18px.
- Переходы между садами имеют высоту 44px и минимальную ширину 96px; переключатель сада — 44×44px. Текстовые подписи сохраняются.
- Полноэкранная информация остаётся доступна; нижняя полоса резервирует 69px плюс safe-area для закреплённой кнопки возврата. Текст не перекрывается.
- Общие цветовые токены, камера, единственный renderer, поведение раскрытия информации и сохранение мемориалов не меняются.

## Проверка

- `pnpm lint`, `pnpm typecheck`, `pnpm test:unit` (168/168), `pnpm build`, `git diff --check` — прошли.
- Playwright: 16 сценариев памятника прошли на RU/EN desktop/mobile; 14 сценариев новой колонки и разворачивания/восстановления карты прошли; 4 матричных сценария 320×568, 390×390, 320×450, 844×390 прошли после явного перехода теста в клавиатурный режим перед проверкой focus-visible. Touch targets меню измеряются после анимации Nuxt UI, а не во время её масштабирования.
- Отдельно прошли 2 проверки диагностики: desktop/390/320px, вложенный FPS-список, мобильный контрольный прогон и отмена. Диагностика сохраняет родительский More открытым, пока работает её панель; наружное закрытие не прерывает её неявно. Смена сада в её прогоне не закрывает родительское меню.
- Добавлен общий test-helper для раскрытия вторичных действий. Прежние сценарии сохраняют доступ к действиям; при сравнении пейзажа временное меню закрывается/маскируется, чтобы изменение текста кнопки не считалось изменением погоды. Полный продуктовый/визуальный набор повторно не запускался: изменения ограничены управлением визуализациями.
- `designmd lint DESIGN.md`: 0 ошибок, 16 существующих предупреждений CSS-потребителей Model B.
- Статический strict-аудит: 0 unresolved, 4 ложных срабатывания на библиотечных триггерах Nuxt UI Popover (3 прежних и новый More). Их клики и Escape проверены браузером; обработчики ради статической эвристики не дублировались. JSON — `test-results/mobile-column-audit.json`.
- Просмотрены PNG колонки, открытого меню и памятника. Скриншоты для просмотра: `test-results/mobile-column-final-evidence/`.

После Escape из развёрнутого мобильного сада фокус возвращается на видимую кнопку More. Завершение подготовки сцены также сохраняет фокус в уже открытых элементах управления.
