# Первый canvas-прототип садов

## Задача

Показать четыре абстрактных сада и открывать по нажатию территорию с местами памяти питомцев. Объём первого шага уточнён в блоке 4 роадмапа до реализации.

## Решение

- Страница `/ru/gardens` / `/en/gardens`, вход с первого блока лендинга.
- Клиентский PixiJS: геометрические сады, деревья, дорожки и памятные камни с лапками. Четыре локальных набора по 12/10/16/14 мест, вымышленные имена, без БД и API.
- Выбор через canvas либо HTML-кнопки; query-параметр сохраняет выбор для обновления, истории и смены языка. После смены сада фокус переходит к заголовку.
- Canvas подстраивается под контейнер. Абсолютное позиционирование элемента устраняет влияние его внутреннего размера на высоту мобильной сцены.
- Отрисовка при изменении состояния и наведении, очистка PixiJS и ResizeObserver при уходе. Ошибка и повторная попытка при недоступной графике.
- Добавлена отдельная конфигурация `playwright.ui.config.ts` для публичного UI без PostgreSQL/Mailpit.

## Проверки

- `corepack pnpm lint` — успешно.
- `corepack pnpm typecheck` — успешно.
- `corepack pnpm build` — успешно; остаются предупреждения зависимостей Nuxt/Iconify/Zod.
- `corepack pnpm exec playwright test --config=playwright.ui.config.ts` — 28 passed: 10 проверок садов и 18 существующих проверок лендинга/темы, desktop и mobile.
- Сценарии садов: реальные клики/касания всех четырёх участков, возврат, клавиатура, история, обновление, RU/EN, изменение размера, повторное монтирование, ошибка и восстановление renderer.
- Визуально просмотрены снимки обзора на desktop и территории на mobile; исправлено растяжение мобильного canvas.

Полный набор авторизации с БД в этой задаче не запускался. Создание мемориалов, карточки объектов, API и управление камерой относятся к следующим шагам. Подробности: [описание прототипа](../docs/garden-canvas.md).
