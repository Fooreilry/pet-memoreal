# CI для проверок проекта

## Задача

Выполнить последний пункт блока 1: добавить установку по lockfile, lint, typecheck и build в CI. В репозитории не было workflow; Git remote ещё не настроен.

## Решение

- Добавлен `.github/workflows/ci.yml` для `push`, `pull_request` и ручного запуска на Ubuntu с Node.js 24.
- Corepack использует закреплённый pnpm из `package.json`; `--frozen-lockfile` запрещает незаметное изменение `pnpm-lock.yaml`.
- Команды и границы текущего CI описаны в `dev/docs/ci.md`. PostgreSQL и `.env` для этих проверок не требуются.

## Проверка

- `corepack pnpm install --frozen-lockfile`, `lint`, `typecheck` и `build` прошли локально.
- Workflow разобран YAML-парсером; три события запуска и шесть шагов присутствуют.
- Сборка отдельно прошла без файла `.env`; локальный файл восстановлен после проверки.
- Выполнение на GitHub станет доступно после настройки remote и публикации репозитория; отправка изменений не выполнялась.
