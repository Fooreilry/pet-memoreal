# Доступное меню садов на низком мобильном экране

## Проблема

В альбомной ориентации меню переключения сада ограничивалось высотой всего viewport, хотя под его кнопкой оставалось меньше места. Контейнер Nuxt UI Popover обрезал нижнюю ссылку «Все сады».

## Решение

Только в существующем compact media-профиле `gardens.vue` меню учитывает фактическую доступную высоту из `--reka-popover-content-available-height` и нижнюю safe area. Заголовок и ссылка возврата не сжимаются; при нехватке места прокручивается только список четырёх садов. Сохраняются исходные размеры целей, порядок, маршруты, Nuxt UI focus/Escape и тема глобальных полос прокрутки.

Desktop CSS и настройки позиционирования Popover не меняются.

## Проверка

Регрессионные браузерные сценарии проверяют реальное пересечение ссылки с viewport и обрезающими предками, касание и возврат в обзор, прокрутку списка, RU/EN, смену ориентации при открытом меню и исходную desktop-геометрию.

- На предыдущей сборке тест воспроизвёл ошибку: видимая высота ссылки составляла 0 из 44px при 844×390.
- На новой изолированной production-сборке прошли семь новых сценариев: RU/EN на 844×390 и 667×375, поворот открытого меню, desktop. Также проверены Tab с автоматической прокруткой до последнего сада и Escape с возвратом фокуса. Семь остальных сочетаний test/project намеренно пропущены по профилю устройства.
- Пройдены `pnpm lint`, `pnpm typecheck`, `pnpm test:unit` (182 теста), `pnpm build`.
- Пройдены ещё шесть существующих сценариев garden shell: RU/EN, desktop/mobile, меню и Escape в развёрнутой карте. Английский мобильный сценарий сначала выявил погрешность DOMRect 43.999992px для 44px кнопки More; в трёх проверках размера expansion-кнопки добавлен допуск 0.01px, повторный запуск прошёл. Это тестовая погрешность, стили More не менялись.
- Строгий статический UI-аудит сохранил четыре ранее известные ложные находки `actionless-button` у триггеров Nuxt UI Popover. Новых находок нет; реальное открытие меню проверено браузером.
- Снимки: `test-results/landscape-menu-final/`; тест подключён к `playwright.ui.config.ts`.
