# Выход на лендинг и видимость перехода наверх

## Задача

После успешного выхода из кабинета или меню садов открывать гостевой лендинг. Показывать закреплённую ссылку «Наверх» только после начала прокрутки, скрывать при возврате к началу.

## Решение

- Оба действия выхода очищают кеш Nuxt и переходят на главную текущего языка с `replace`. При ошибке запроса пользователь остаётся на исходной странице с действующей сессией и возможностью повторить выход.
- Ссылка «Наверх» скрыта при SSR и при `scrollY <= 0`. После прокрутки появляется в прежнем фиксированном положении. Пассивный обработчик читает только положение прокрутки; `pageshow` учитывает восстановление страницы браузером. При уходе оба обработчика снимаются.
- Сама ссылка использует нативный `href="#top"`. Без JavaScript необязательный контрол скрыт, статическое содержимое и обычные ссылки лендинга доступны.
