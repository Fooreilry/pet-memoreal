# Язык интерфейса

Все страницы используют единые адреса: `/`, `/register`, `/login`, `/account`, `/gardens?garden=lake`. Языка в URL нет; домен сайта остаётся прежним.

При первом запросе сервер получает страну из заголовка Vercel `x-vercel-ip-country`: `RU` означает русский, любая другая страна или отсутствие страны — английский. Язык браузера не участвует в выборе. На localhost страна обычно неизвестна, поэтому интерфейс открывается на английском. VPN может изменить определённую страну.

Переключатель RU/EN сохраняет ручной выбор на год в cookie `petmemoreal_locale` (HttpOnly, SameSite=Lax; Secure на Vercel). Выбор имеет приоритет над страной и сохраняется при переходах, перезагрузке и выходе из аккаунта. Чтобы снова использовать автоматическое определение страны, удалите эту cookie.

Переключатель работает обычной ссылкой через `/language`, в том числе без JavaScript. Путь и query-параметры выбранного сада/мемориала сохраняются; при включённом JavaScript сохраняется также hash. Допускается только локальный адрес возврата. Старые адреса `/ru/...` и `/en/...` перенаправляются с кодом 301 на адрес без префикса, сохраняя query; старый префикс не переопределяет страну или ручной выбор. Ранее выданные ссылки регистрации и восстановления продолжают работать.

`@nuxtjs/i18n` использует `no_prefix`, `detectBrowserLanguage: false`. Плагин `app/plugins/visitor-locale.ts` устанавливает язык до первого рендера через `i18n:beforeLocaleSwitch`; результат передаётся клиенту в payload Nuxt, чтобы избежать смены языка при гидрации. Персонализированные HTML-страницы имеют `private, no-store`. Предварительная генерация главной не применяется.

## Проверка

- `corepack pnpm test:unit` — правила страны, cookie и безопасных перенаправлений.
- `corepack pnpm exec playwright test --config=playwright.ui.config.ts locale.spec.ts` — SSR, гидрация, ручной выбор, старые ссылки и работа без JavaScript.
- `corepack pnpm test:vercel` — проверки серверного runtime.

На Vercel дополнительные переменные и внешние сервисы геолокации не нужны. `BETTER_AUTH_URL` остаётся origin сайта без пути.

Источники: [заголовки Vercel](https://vercel.com/docs/headers/request-headers), [runtime hooks Nuxt i18n](https://i18n.nuxtjs.org/docs/guide/runtime-hooks).
