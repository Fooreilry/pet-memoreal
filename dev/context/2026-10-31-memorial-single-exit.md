# Один выход из вида памятника

## Запрос и решение

Удалён крестик справа сверху, дублирующий «В сад». В правой группе остались существующие погода и пауза. Escape и выход через «В сад» продолжают возвращать фокус на выбранный памятник.

`GardenMemorials.vue` теперь направляет начальный фокус на возврат. В раскрытой мобильной карточке сохраняется фокус на контроле сворачивания. Обновлены проверки без удалённого селектора и текущие контракты DESIGN.md, UX-CONTRACT.md, документация сада.

## Проверка

- `pnpm lint`, `pnpm typecheck`, `pnpm build`, `git diff --check` — успешно.
- `pnpm test:unit` — 182/182.
- Целевые Playwright-сценарии — 34/34 на desktop/mobile: RU/EN, возврат, Escape, начальный и восстановленный фокус, глубокие ссылки, поворот, длинная история, погода и пауза.
- Responsive-сценарии повторно прошли 4/4 с ожиданием окончания перестроения сцены перед снимком. Проверяется отсутствие крестика и наличие ровно двух действий справа при включённом движении.
