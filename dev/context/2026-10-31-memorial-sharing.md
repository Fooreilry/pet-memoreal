# Поделиться местом памяти

Размещение кнопок обновлено последующим запросом: [возврат сверху и отправка в footer](2026-10-31-memorial-action-layout.md). Ниже сохранена история первоначальной реализации отправки.

## Задача

Добавить в полную информацию о питомце кнопку отправки ссылки, согласованную с оформлением карточки.

## Реализация

- `GardenMemorialDetail.vue`: кнопка под именем и датами, обводка primary, существующие шрифты и радиусы, цель 44px. Положение не увеличивает закреплённый footer и не мешает мобильному раскрытию.
- Системный Web Share вызывается непосредственно по нажатию. При отсутствии поддержки, `canShare=false` или ошибке — Clipboard API. Отмена `AbortError` не вызывает копирование.
- Публичный URL содержит только текущий origin, маршрут сада и `garden`/`memorial`; исходные query/hash не переносятся. Передаются имя и название сада, без текста истории и автора.
- После записи в буфер — локализованный общий toast. При отказе буфера — поле Nuxt UI с доступной подписью, пояснением, выделением ссылки и ручным копированием. Повторное нажатие позволяет повторить операцию.
- Busy-состояние блокирует дубли; отмена/завершение возвращает фокус, когда это уместно. Закрытие/смена карточки инвалидирует поздний переход к копированию и уведомления.
- RU/EN строки находятся в `memorial.sharing`; share/check включены в локальный набор иконок. Общие правила добавлены в DESIGN.md, UX-CONTRACT.md и документацию сада.

## Проверка

- `pnpm lint`, `pnpm typecheck`, `pnpm build`, `git diff --check` — успешно.
- `pnpm test:unit` — 178/178.
- Playwright `memorial-sharing.spec.ts` + `memorial-detail.spec.ts` — 38/38 на desktop/mobile. Покрыты чистый URL и гостевое открытие, native/share/cancel, duplicate busy, clipboard fallback, недоступный буфер, повтор, демонстрационный мемориал и поздняя ошибка закрытой карточки. Web Share и Clipboard замоканы, чтобы не открывать системные окна и не менять реальный буфер.
- После визуальной проверки 320px исправлена прокрутка к полю ручного копирования. Четыре затронутых сценария повторно прошли с проверкой видимости поля, фокуса и выделения всей ссылки.

- Визуально проверены RU/EN, desktop и мобильный вид, включая ручное копирование.
