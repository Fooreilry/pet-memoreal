# Подключение демобазы Neon

## Задача

Пользователь предоставил pooled и direct подключения для настройки демо Vercel.

## Выполнено

- Создан локальный `.env.vercel` с `DATABASE_URL`, `DIRECT_URL` и `PG_POOL_MAX=3`. Файл исключён из Git и CLI-загрузки Vercel; локальный `.env` не менялся.
- Через direct endpoint успешно применены подготовленные миграции.
- Seed добавил справочные сады без тестовых пользователей и мемориалов.
- Через pooled endpoint проверены TLS с валидацией сертификата, схема приложения и наличие четырёх садов карты.

## Следующие настройки

Нужны Resend, постоянный домен приложения, секрет Better Auth и переменные окружения Vercel по [инструкции](../docs/vercel-deployment.md). Публикация приложения и проверка доставки писем ещё не выполнялись. Поскольку пароль подключения передан в переписке, перед публикацией рекомендуется заменить его и обновить локальные и облачные переменные; новое значение в чат не отправлять.

Изменения касаются только конфигурации и состояния демобазы. Код приложения не менялся, повторный браузерный прогон не требовался.
