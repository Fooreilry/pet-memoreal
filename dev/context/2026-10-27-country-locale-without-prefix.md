# Язык по стране без префикса URL

## Задача

Убрать `/ru` и `/en` из адресов. При первом заходе из России показывать русский, во всех других случаях — английский.

## Решение

- Nuxt i18n: `no_prefix`, английский fallback, браузерное определение отключено.
- До SSR выбирается язык по `x-vercel-ip-country`; выбор передаётся клиенту через payload. Нет внешних геолокационных запросов или тяжёлой IP-базы.
- Сохранён переключатель с годовой cookie ручного выбора, работающий также без JavaScript. Проверяется локальность адреса возврата.
- Старые ссылки перенаправляются на адреса без префикса; query-параметры мемориалов и старые callback-ссылки авторизации поддерживаются.
- Обновлены правила кеширования, loopback origin, безопасные auth redirects, документация и URL в существующих сценариях. Локаль тестов теперь задаётся отдельной cookie, независимо от маршрута.

## Проверка

Добавлены unit- и Playwright-сценарии страны, SSR/гидрации, выбора языка, ссылок без JavaScript и защиты redirect.

- `test:unit`: 37 успешно; `lint`, `typecheck`, `build`: успешно.
- Лендинг, тема, выбор садов и локализация: 52 браузерных сценария успешно. Финальная повторная проверка локализации с сохранением hash: 14 успешно.
- Основной прогон авторизации, кабинета, ролей, карты и мемориалов: 102 успешно, 10 пропусков для неподходящего устройства/дублирующих серверных проверок. Исправлены шесть устаревших ожиданий: язык нового независимого гостя теперь задаётся отдельно от ссылки, URL переключения не содержит префикса. Повтор обоих файлов: 20 успешно, 2 пропуска; все шесть исправленных случаев прошли.
- `test:vercel`: 2 успешно — выбор страны при SSR и существующие проверки БД/ограничений запросов.
- `build:vercel`: успешно; статический `index.html` не генерируется, главная остаётся динамической.

Docker PostgreSQL и Mailpit запущены локально для проверок. E2E создаёт и удаляет собственные временные базы; Neon не затрагивается. Логи проверок находятся в игнорируемой `.cache/locale-*.log`.

Настройка описана в [документации локализации](../docs/localization.md). Публикация на Vercel и изменения удалённой базы в эту задачу не входят.
